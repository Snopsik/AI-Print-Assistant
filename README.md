# AI Print Assistant

Облачный ИИ-помощник для OrcaSlicer с поддержкой текстовых и зрительных моделей. Анализирует параметры печати, фотографии и скриншоты, помогает заметить отлипание детали, провисшие мосты, сдвиг слоёв и другие дефекты. Поддерживает совместную работу отдельных моделей логики и зрения, а также обязательное подтверждение потенциально опасных действий пользователем.

## Возможности

- отдельная вкладка с чатом внутри OrcaSlicer;
- чтение текущей модели, активных профилей и основных настроек печати;
- получение списка доступных моделей через `/models`;
- пометки и фильтр моделей с поддержкой зрения;
- единый режим для универсальной модели или раздельные API для текста и зрения;
- предустановки OpenAI, Google Gemini, GLM / Z.AI и OpenRouter, а также произвольный HTTPS endpoint;
- анализ JPEG, PNG и WebP, прикреплённых через кнопку **«Фото»**;
- повторная проверка неясных деталей зрительной моделью по запросу текстовой;
- рекомендации по осмотру, паузе или остановке с подтверждением пользователя;
- работа без сторонних Python-зависимостей.

> Плагин не изменяет профили и G-code и не отправляет команды принтеру. Подтверждённые действия в текущей версии выполняются вручную.

## Требования

- Windows 11;
- OrcaSlicer 2.5.0 Alpha с поддержкой Python-плагинов;
- облачный API с OpenAI-совместимым форматом `/chat/completions`.

Для получения списка моделей провайдер также должен поддерживать `/models`. Если этот метод недоступен, название модели можно ввести вручную.

## Установка

1. Скачайте `orca_ai_assistant_vision_win_x86_64.py`.
2. В OrcaSlicer откройте **File → Plugins**.
3. Нажмите стрелку возле **Browse plugins → Install local plugin** и выберите файл.
4. Включите плагин галочкой **Activate**.
5. Разрешите сетевые запросы и создание фонового потока, когда OrcaSlicer запросит разрешения.
6. Откройте вкладку **AI Print Assistant → API и модели**.
7. Выберите режим и провайдера из списка. Для собственного OpenAI-совместимого сервиса выберите **«Свой endpoint»** и введите полную HTTPS-ссылку до `/chat/completions`.
8. Укажите модель и API-ключ, затем сохраните настройки.

Для публикации через Orca Cloud используйте версию **2.1.0** и файл с суффиксом `win_x86_64`.

## Безопасность и конфиденциальность

API-ключи хранятся локально в конфигурации плагина без шифрования. Вопросы, изображения и выбранный контекст отправляются указанному облачному провайдеру. Адреса принтера, токены подключения, пользовательский G-code и неперечисленные параметры профиля не включаются в контекст.

Диагностика по одному кадру может быть ошибочной. Перед паузой, остановкой или изменением параметров проверяйте состояние принтера и результат в Preview.

## Проверка

```bash
python test_orca_ai_assistant_vision.py
```

Автотесты используют имитацию OrcaSlicer и облачных API; реальные сетевые запросы и ключи для их запуска не нужны.
