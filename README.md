# AI Print Assistant

Облачный ИИ-помощник для OrcaSlicer с поддержкой текстовых и зрительных моделей. Анализирует параметры печати, фотографии и скриншоты, помогает заметить отлипание детали, провисшие мосты, сдвиг слоёв и другие дефекты. Поддерживает совместную работу отдельных моделей логики и зрения, а также обязательное подтверждение потенциально опасных действий пользователем.

## Возможности

- чат с чтением модели, геометрии, активных профилей и основных настроек печати;
- структурированные ответы с заголовками, списками и безопасным отображением Markdown без сырой разметки;
- полноширинная вкладка и dock-панель на всю высоту с адаптивными карточками изменений;
- единая универсальная модель или раздельные API для текстовой логики и зрения;
- получение списка моделей через `/models` и фильтр моделей с пометкой зрения;
- OpenAI, Google Gemini, GLM / Z.AI, OpenRouter и произвольный OpenAI-совместимый HTTPS endpoint;
- анализ фотографий с повторной верификацией неясных деталей второй моделью;
- кнопка **«Предложить настройки»** с интерактивным списком «было → станет» и обоснованием;
- применение подтверждённых изменений через штатные транзакции профилей OrcaSlicer;
- кнопка **«Применить рекомендации ИИ»** с преобразованием текстовых советов в проверяемые параметры;
- откат последней партии настроек, включая восстановление после частичной ошибки применения;
- опциональное автоматическое применение структурированных рекомендаций после анализа;
- сохраняемое описание реального принтера и его модификаций для всех видов AI-анализа;
- чтение отфильтрованной конфигурации и состояния Klipper через Moonraker;
- ручной и автоматический AI-анализ G-code с учётом предыдущего анализа модели;
- автоматический мониторинг прямого URL снимка камеры с заданным интервалом;
- dock-панель рядом с 3D-видом на вкладках **Prepare / Подготовка** и **Preview / Нарезка**;
- рекомендации по осмотру, паузе или остановке только с подтверждением пользователя;
- работа без сторонних Python-зависимостей.

> Плагин не перезаписывает G-code и не отправляет команды принтеру. Подтверждённые изменения применяются к активным профилям и остаются несохранёнными, пока пользователь сам не сохранит профиль. Пауза и остановка выполняются вручную.

## Требования

- Windows 11;
- свежая OrcaSlicer 2.5.0 Alpha с Python-плагинами;
- для применения настроек — API `orca.host.preset` с транзакциями `begin_update/set/commit`;
- для dock-панели — API `orca.host.ui.create_dock_panel`;
- облачный API с OpenAI-совместимым форматом `/chat/completions`;
- для чтения Klipper — доступный с этого компьютера Moonraker.

В ранних сборках Alpha часть этих API может отсутствовать: чат сохранит работоспособность, а недоступная функция покажет сообщение о необходимости обновить OrcaSlicer. Для получения списка моделей провайдер должен поддерживать `/models`; иначе название модели можно ввести вручную.

## Установка

1. Скачайте `orca_ai_assistant_vision_win_x86_64.py`.
2. В OrcaSlicer откройте **File → Plugins**.
3. Нажмите стрелку возле **Browse plugins → Install local plugin** и выберите файл.
4. Включите плагин галочкой **Activate**.
5. Разрешите сетевые запросы и создание фоновых потоков, когда OrcaSlicer запросит разрешения.
6. Откройте **AI Print Assistant → Настройки → API**.
7. Выберите режим и провайдера. Для своего сервиса выберите **«Свой endpoint»** и введите полную HTTPS-ссылку до `/chat/completions` либо базовый адрес, например `https://example.com/v1`; суффикс добавится автоматически.
8. Укажите модель и API-ключ, затем сохраните настройки.

Для публикации через Orca Cloud используйте версию **2.6.0** и файл с суффиксом `win_x86_64`. Окно настроек закрывается крестиком в правом верхнем углу или клавишей Escape.

## Настройки под модель

1. Нажмите **«Предложить настройки»** во вкладке или dock-панели.
2. Проверьте каждый пункт, старое и новое значение и обоснование.
3. Нажмите **«Подтвердить и применить»**. Если рекомендации даны только текстом, нажмите постоянно доступную кнопку **«Применить рекомендации ИИ»**: плагин дополнительно запросит у текстовой модели точные параметры, проверит их и применит после вашего подтверждения.
4. Проверьте параметры в интерфейсе Orca, сохраните профиль при необходимости и выполните нарезку заново.
5. Для восстановления прежних значений нажмите **«Откатить последнее применение»** или **«Откатить»** в dock-панели. Кнопка появляется после применения и остаётся доступной при частичной ошибке.

AI может предложить только разрешённые ключи; числовые значения проходят проверку безопасных диапазонов. Смена `printer_model` запрещена. Перед применением плагин проверяет наличие прежнего значения каждого параметра и сохраняет одну последнюю партию для отката. Изменения применяются пакетно для каждой категории через Orca, но не сохраняются на диск автоматически.

Для автоматического режима откройте **«Настройки» → «Настройки принтера» → «Применение рекомендаций»** и включите **«автоматически применять проверенные настройки после анализа»**. По умолчанию опция выключена. Она затрагивает только структурированные `setting_changes`, полученные после анализа; текстовые советы без таких параметров автоматически не применяются. Откат всегда выполняется вручную.

## Модификации принтера

В **«Настройки» → «Настройки принтера» → «Модификации принтера»** укажите реальную модель принтера и установленные апгрейды. Поле по умолчанию пустое: плагин не содержит чужих предустановленных принтеров или модификаций, а каждый пользователь описывает только своё оборудование.

Описание передаётся при анализе модели и фотографий, преобразовании рекомендаций в настройки, проверке G-code и мониторинге камеры. Оно имеет приоритет над названием пресета. При появлении других модификаций дополните или замените текст и сохраните настройки. Неизвестные характеристики модификаций не следует выдумывать: при необходимости добавьте проверенные значения в описание вручную.

## Klipper / Moonraker

1. Откройте **«Настройки» → «Настройки принтера» → «Klipper / Moonraker»**.
2. Укажите базовый URL, например `http://printer.local:7125`, без логина, пароля и параметров запроса.
3. Нажмите **«Загрузить настройки Klipper»**. URL сохраняется автоматически, а кнопка повторной загрузки обновляет снимок перед новым анализом.

Плагин использует POST `/printer/objects/query` только для чтения `configfile`, `gcode_move`, `toolhead`, экструдера, стола, вентилятора и состояния печати. В AI-контекст попадают разрешённые параметры движения, Pressure Advance, экструзии, PID, охлаждения, Input Shaper и калибровки стола. Пины, серийные адреса и прочие секреты не включаются. Снимок хранится в памяти до перезапуска плагина и не записывается в публичную конфигурацию.

При диагностике «макарон», отлипания и других проблем ИИ может рекомендовать точную секцию и параметр Klipper с текущим и предлагаемым значением. Такие рекомендации не входят в автоприменение Orca: изменение `printer.cfg`, команды калибровки, перезапуск и сохранение `SAVE_CONFIG` пользователь выполняет самостоятельно после проверки. Плагин не вызывает `/printer/gcode/script` и не отправляет команды принтеру.

## Анализ G-code

Для ручной проверки нажмите **«Проверить G-code»** и выберите текстовый файл до 8 МБ.

Для автоматической проверки после нарезки откройте **Process → Others → Slicing Pipeline Plugin** в режиме Advanced и выберите **AI G-code Review**. После `psGCodePostProcess` плагин передаст текстовой модели статистику команд, температуры, охлаждение, скорости, предупреждения и ограниченные начальный/конечный фрагменты файла, а также предыдущий анализ модели. Автоматический режим принимает файлы до 64 МБ. Результат появится во вкладке и dock-панели.

## Мониторинг камеры

1. В **«Настройки» → «Настройки принтера»** укажите прямой URL одного JPEG, PNG или WebP снимка, например `http://printer.local/webcam/?action=snapshot`.
2. Задайте интервал от 30 до 3600 секунд и сохраните настройки.
3. Нажмите **«Запустить мониторинг»**. Каждый новый снимок анализируется выбранной облачной моделью с учётом текущего контекста.

MJPEG-видеопотоки и видео не поддерживаются. URL с логином и паролем отклоняется. Каждый снимок отправляется облачному провайдеру. Плагин продолжает цикл после временной ошибки и сообщает о ней; остановить мониторинг можно той же кнопкой.

## Безопасность и конфиденциальность

API-ключи, URL камеры и URL Moonraker хранятся локально в конфигурации плагина без шифрования. Вопросы, изображения, выбранный контекст, отфильтрованный снимок Klipper и данные для обзора G-code отправляются указанному облачному провайдеру. Пользовательский G-code целиком в обычный контекст чата не включается.

Диагностика по одному кадру или ограниченным фрагментам G-code может быть ошибочной. Перед паузой, остановкой или изменением параметров проверяйте состояние принтера и результат в Preview. Плагин не управляет принтером напрямую.
